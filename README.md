# RONEN DISPLAY — Industrial Display Technical Reference

Open engineering notes from [RONEN DISPLAY](https://odmlcd.com) — industrial TFT LCD & OLED module manufacturer (factory-direct, 190+ standard models).

This repository collects **generic, vendor-neutral technical notes** on display selection, interfaces and optical design, maintained by our application engineers. Every note links back to the free calculators and guides on [odmlcd.com](https://odmlcd.com) so you can run the numbers yourself.
